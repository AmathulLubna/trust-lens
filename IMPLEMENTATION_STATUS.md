## Remaining limitations

- No Indian telephony, voice-cloning, Hindi/English ASR, multilingual scam-rule or demographic performance evaluation has been established. The pinned public model is a baseline, not a validated SIH classifier. The 0.7 acoustic warning threshold and RMS/clipping gates are explicit prototype policy choices. They are not calibrated probabilities or benchmarks.
- Intent split across microphone segments can be missed. Nearby speakers are not separated or identified. Browser permissions, background throttling, screen lock, tab navigation, device audio routing and physical speaker playback still need controlled device testing. Browser gaps remain uncertainty, not coverage guarantees.
- The synchronous Python service permits only two uploads/inferences per process but has no hard inference kill deadline or durable worker recovery. The web deadline is 60 seconds, final drain is 35 seconds; slow or long CPU analysis can yield unavailable/missing coverage while service cleanup finishes later. Process termination can leave temporary backend files; operators need supervised worker/orphan cleanup before production. Normal success/error cleanup is regression-tested.
- Notification transport interruptions are conservatively unknown and are not automatically resent. Provider reconciliation and delivery receipts are required to resolve an attempt that produced no provider ID. A recipient's browser vibration support is device-dependent; preference changes apply to a newly started microphone session.
- Convex schema additions are compatibility-oriented and keep existing schema-validation configuration. Existing deployed data should be inspected before a separate validation/migration rollout. Large historical ledgers can exceed one clear-history transaction; production-scale paginated deletion is not verified.
- Existing unowned Python case records are inaccessible after the additive ownership migration. Assigning old owners requires a separately reviewed migration; no private record was reassigned. Trusted speaker/reference enrollment is explicitly unavailable (`501`). Backend API authentication now requires a trusted gateway; Android integration is outside this task.
- Python dependency pins were exercised in the existing reference environment, not independently security-audited or installed from scratch. Source paths, user training experiments and existing local credentials remain preserved; do not publish the local recovery backup.
