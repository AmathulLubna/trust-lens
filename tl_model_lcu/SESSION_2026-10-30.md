## Publish a separate LCU frontend on Vercel

Vercel setup was documented, but a separate publicly hosted LCU frontend was
**not configured or verified** in this session.

1. Create a new Vercel project, e.g. `trustlens-lcu`, from
   `AmathulLubna/trust-lens`. Keep the original Vercel project as it is.
2. Use production branch **LCU** under Settings → Environments → Production →
   Branch Tracking. Framework **Vite**, repository root, Node **24.x**, install
   `npm ci`, build `npm run build`, output **dist**.
3. Add these Vercel Production environment variables, then deploy/redeploy LCU:

   ```dotenv
   VITE_CONVEX_URL=https://outstanding-falcon-217.convex.cloud
   VITE_CONVEX_SITE_URL=https://outstanding-falcon-217.convex.site
   ```

4. Replace the example with the actual new Vercel origin and run:

   ```powershell
   npx convex env set SITE_URL "https://your-new-site.vercel.app" --deployment anirudh-upadhyay:trustlens-lcu:production
   ```

5. Start Terminal 1 above on the operator's laptop, open the Vercel site on
   another device, sign in, connect the detector and test a recording. Terminal 2
   is only for the local frontend; Vercel serves the public frontend.

The laptop must remain awake and online for detection. Quick Tunnels are for
testing, have changing URLs and no uptime guarantee. This is a limited beta
setup, not verified capacity for thousands of simultaneous live checks.
